# 格ゲー技比較ツール（フレーム単位同期比較）

格闘ゲームの「見た目が似ている技」のモーション差を、録画した動画をフレーム単位で比較しながら見分けるためのトレーニングツールです。

**サーバー不要のシングルHTML**（1ファイル）で完結します。ブラウザで開くだけで動作し、GitHub Pages などにもそのまま公開できます。

## デモ（サンプル動画）

画面録画ができない環境でも、ページ内の **「🎬 サンプル動画を生成（デモ用）」** ボタンで、動きの異なる2本のサンプル動画（赤／青）を自動生成し、**A・Bに自動セット**します。録画なしで以下の全機能をすぐ体験できます。

## 主な機能

| 機能 | 内容 |
|---|---|
| 画面録画 | `getDisplayMedia` でゲーム画面（ウィンドウ／タブ）を録画（60fps・高ビットレート） |
| 録画リスト | 保存・A/Bセット・ダウンロード・削除 |
| 同期点の設定 | シークバーで止めた位置を同期点候補にし、±1f／±3f でフレーム単位微調整。**「押して確定」** で緑色の「確定済み ✓」に |
| 同時再生 | A・Bを同期点基準で同時再生（ズレは60msごとに自動補正） |
| 一時停止／最初から再生 | 現在位置からの再開／同期点に戻って再生し直し |
| 自動コマ送り | 1コマ進む間隔（秒）を指定したスロー再生 |
| 手動コマ送り | ±1f／±3f／±5f、キーボード ← / → |
| ループ再生 | ループ区間（秒）ごとに同期点へ戻って繰り返し |
| 比較画面の動画保存 | A/Bを横並びにした比較画面自体をWebMとして書き出し |
| 同期点の永続化 | `localStorage` に保存し、再読み込み後も維持 |

## 技術構成（使用API）

| 技術／API | 用途 |
|---|---|
| HTML / CSS / JavaScript（依存ライブラリなし） | アプリ全体 |
| `getDisplayMedia` | 画面共有による録画 |
| `MediaRecorder` | WebM録画・比較画面の書き出し |
| `URL.createObjectURL` / `revokeObjectURL` | 録画の即時プレビューとメモリ解放 |
| `video.currentTime` | フレーム単位のシーク（±1f／±3f） |
| `setInterval` ＋ `seeked` イベント制御 | 2本の同期補正（60msごと）とプログラムシークの安定化 |
| `requestAnimationFrame` | 自動コマ送りの時間制御 |
| `canvas` ＋ `captureStream()` ＋ `drawImage` | サンプル動画の生成・比較画面の合成 |

## 工夫した点（面接で話す想定）

1. **フレーム単位の比較を「同期点＋確定」の2段階で実現**
   シークバーで止めた位置を候補にし、±1f／±3fで微調整してから「確定」する仕組みに分離。調整と決定を分けることで、誤操作によるズレを防ぎました。

2. **2本の動画の同期ズレを自動補正**
   共通タイムライン（同期点基準）で管理し、60msごとにズレを検出して自動で位置を揃えます。プログラムによるシーク直後の `seeked` イベントを無視することで、補正が原因のカクつきを抑えました。

3. **再生状態の一元管理による安定化**
   再生に関わるリソース（タイマー・アニメーションフレーム・フラグ）を `stopAll()` で必ずリセットしてから開始する設計にし、「2回目以降の再生で挙動がおかしくなる」バグを根本から解消しました。A/Bの再生開始も独立させ、片方の失敗がもう片方を止めないようにしています。

4. **デモ体験の重視（ポートフォリオ向け）**
   録画環境がなくても全機能を試せるサンプル動画の自動生成機能を実装。採用担当者が数クリックで「比較」の価値を体感できます。

5. **サーバーレス・依存ゼロ**
   外部CDNやライブラリに一切依存しないシングルHTML。github.io やローカルのダブルクリックのどちらでも動作します。

## 既知の制約

- 出力形式は **WebM** のみ（MP4書き出しはブラウザ非対応のため不可）
- 画面録画は **映像のみ**（音声なし。画面共有APIの仕様）
- 録画直後のWebMはブラウザによってシークできないことがある → 一度「ダウンロード」して「ファイルを読み込む」で再読込すると改善
- フルスクリーン専用モードのゲームは録画が黒くなることがある → ウィンドウ／ボーダーレス表示で起動
- 比較録画（画面合成）はCPU負荷が高いため、数十秒〜1分程度の録画を推奨
- 動作確認推奨ブラウザ: **Chrome / Edge**（Firefox・SafariはWebM／captureStreamの対応に差あり）

## 動作環境

- Chrome / Edge（最新版）推奨
- その他: 動画ファイルの読み込み・比較再生・サンプル生成・削除などの基本機能は各ブラウザで動作

## GitHub Pages での公開手順

1. GitHub でリポジトリを作成（例: `fighting-game-move-compare`）
2. `index.html` と `README.md` をリポジトリにアップロード
3. リポジトリの **Settings → Pages** を開く
4. **Source: Deploy from a branch** → ブランチ `main`、フォルダ `/ (root)` を選択して Save
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開

（ローカルで試すだけなら、`index.html` をダブルクリックで開くだけで動作します）
